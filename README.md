A tiny courier, four paper puzzle routes, and five parcel deliveries. FOLDLINE is an original grid game about reflecting paper panels across their creases to reconnect the streets.

## Play locally

This project uses static files and plain JavaScript ES modules. From the repository root, run:

```sh
node serve.ts
```

Then open <http://localhost:8080> in desktop Chrome. No build step or external assets are used.

## Controls

- WASD or arrow keys: move along connected roads
- Click a dotted crease twice: select, then fold or unfold its amber panel
- Escape: clear the seam selection, or pause when nothing is selected
- P: pause or resume
- R: restart the current level
- Space / Enter or the on-screen button: start, continue, or replay

Solve the four cities in order: First Fold, Crossroads, Paper Bridge, and Double Delivery. Fold panels into their marked receiving areas, follow only joined roads, and deliver parcels to the numbered green drops. Each level scores remaining time, moves under par, and economical folds.
